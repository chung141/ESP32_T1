# ESCAPE / 32 — 심해의 마지막 신호

해저 연구소의 미로를 탐색하며 15분 안에 세 보안 장치를 해제하고 탈출하는 게임입니다.
인터넷, 외부 라이브러리, 이미지 다운로드 없이 동작합니다.

## 1. 보드 없이 바로 플레이

압축을 푼 후 `index.html`을 Chrome 또는 Edge로 열고 **연습 모드 시작**을 누르세요.
방향키 / WASD로 이동하고 장치 바로 옆에서 E 또는 조사 버튼을 누릅니다.
휴대폰은 화면 아래 방향 버튼을 사용합니다. 모바일 파일 미리보기 대신 브라우저가 필요합니다.

## 2. ESP32-S3 실물 연결

이 코드는 **MicroPython 펌웨어가 설치된 ESP32-S3**용입니다. PC용 Python에서 main.py를 실행하는 코드가 아닙니다.
기존 보드 파일은 먼저 PC에 백업하세요. 같은 이름의 main.py를 저장하면 기존 시작 프로그램이 바뀝니다.

1. ESP32를 USB로 연결하고 Thonny에서 해당 ESP32 MicroPython 인터프리터와 포트를 선택합니다.
2. `config.py`를 열어 아래 두 값만 자신의 **2.4 GHz Wi-Fi** 이름/비밀번호로 바꿉니다.
   ```python
   WIFI_SSID = "내 와이파이 이름"
   WIFI_PASSWORD = "내 와이파이 비밀번호"
   ```
3. `config.py`, `main.py`, `index.html` 세 파일을 **ESP32 장치의 최상위 폴더**에 같은 이름으로 저장합니다. PC 폴더에만 저장하면 보드에서 읽을 수 없습니다.
4. 보드를 재시작하거나 Thonny에서 main.py를 실행합니다.
5. 셸에 `Open in phone browser: http://192.168.x.x`가 출력되는지 확인합니다.
6. 휴대폰과 노트북을 보드와 **같은 Wi-Fi**에 연결합니다.
7. 휴대폰 Safari/Chrome의 주소창에 **셸에 나온 전체 http://주소**를 입력합니다.
8. 게임 화면에서 **ESP32 연결 후 시작**을 누릅니다.

과거에 사용한 `192.168.0.75`가 계속 유지된다는 보장은 없습니다. 반드시 이번 실행의 주소를 사용하세요.
휴대폰에 HTML을 복사해서 여는 방식이 아니라, ESP32에 접속하면 보드가 HTML을 내려줍니다.
화면과 API가 같은 주소를 사용하므로 다른 출처 간 요청(CORS)이나 HTTPS → HTTP 혼합 콘텐츠 요청이 필요하지 않습니다.

## 3. LED 배선과 동작

| 색상 | GPIO | 기능 |
|---|---:|---|
| 빨강 | 15 | 오답 시 약 1.5초, 시간 종료 시 계속 점등 |
| 초록 | 16 | 통신 퍼즐 신호, 최종 탈출 성공 시 계속 점등 |
| 노랑 | 17 | 작전 진행 중 대기 표시, 통신 퍼즐 신호 |

일반적인 배선은 GPIO → 220~330Ω 저항 → LED 긴 다리(+) / 짧은 다리(-) → GND입니다.
기존에 저항과 공통 GND가 연결되어 있는지 확인하세요. GPIO 번호이며 보드의 물리적 핀 순번이 아닙니다.
LOW에서 켜지는 LED 모듈이면 config.py의 `LED_ACTIVE_HIGH = False`로 변경합니다.

통신실 B의 신호 재생을 누르면 네 번의 색상 신호가 실제 LED와 화면에 표시됩니다.
화면은 응답 수신 후 타이밍을 재현하는 표시이며 실제 GPIO를 읽은 피드백은 아닙니다.
Wi-Fi 지연에 따라 화면과 실물의 시작 시점은 조금 다를 수 있습니다.

## 4. 게임 규칙

- A 전력실 → B 통신실 → C 격리실 → EX 탈출구 순서입니다.
- 현재 목표는 지도에서 밝은 황갈색으로 표시됩니다. 민트색 원이 플레이어입니다.
- 장치와 같은 칸 또는 상하좌우 바로 옆 칸에서 조사할 수 있습니다.
- 정답을 맞혀도 자동 탈출되지 않습니다. 마지막으로 EX를 조사해야 합니다.
- 오답마다 20초 차감. 형식이 틀린 입력은 제출 전에 안내합니다.
- 힌트와 기록 화면을 보는 동안에도 시간이 흐릅니다.
- 실물 모드는 보드 한 대당 하나의 작전을 공유합니다. 다른 기기의 새 게임 시작도 보드의 진행을 초기화합니다.
- 새로고침 후 모드를 다시 시작하면 새 작전이 시작됩니다. 진행 저장 기능은 없습니다.
- 장치 연결이 끊기면 연결 오류를 표시합니다. 자동으로 연습 모드로 바꾸지 않습니다.

## 5. 연결이 안 될 때

- Wi-Fi 실패: 2.4 GHz인지, SSID/비밀번호가 맞는지 확인합니다. 약 30초 후 실패를 출력합니다.
- 페이지가 안 열림: 보드 실행 유지, 같은 Wi-Fi, 현재 IP, `http://`를 확인합니다.
- 게스트 Wi-Fi/학교 공용 Wi-Fi는 기기 간 통신을 차단할 수 있습니다. 기기 간 연결이 허용된 개인 공유기를 사용합니다.
- `No module named machine`: PC용 Python으로 실행한 것입니다. ESP32 MicroPython 인터프리터를 선택합니다.
- `index.html` 파일 오류: 파일이 보드 최상위에 저장되어 있는지 확인합니다.
- LED가 반대로 동작: active-high 설정과 배선을 확인합니다.
- 로컬 네트워크 접근 허용을 묻는 경우 해당 브라우저에서 보드 연결을 허용합니다.
