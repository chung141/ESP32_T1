바다낚시 3분 챌린지 (v3) — ESP32-S3
====================================

[바뀐 것]
- 1인칭 배낚시, 물고기 5종(고등어·우럭·참돔·방어·참다랑어), 3분 점수 경쟁
- 초록 LED 추적 강화: 밝은 LED 중심 인식, 다른 초록 물체 무시, 떨림 보정
- 챔질 방법 3가지: LED를 위로 홱 / 기울기 센서 / 엔코더 버튼
- 3분 뒤 🔪 손질 리듬게임 (기울기 센서 = 물고기 뒤집기)
- 입질·낚시 성공 때 ESP32 부저가 울림

[ESP32는 다시 안 올려도 됩니다]
이미 보드에 저장한 main.py(v2) 그대로 사용합니다. 배선도 그대로.

[실행]
1. ESP32 USB 전원 연결 (Thonny 닫아도 됨)
2. 이 폴더 주소창에 cmd 입력 → Enter
3. Thonny에 나온 ESP32 IP 확인 → launch.bat 그IP 입력 → Enter
   (예: launch.bat 172.30.1.93)
4. 브라우저 http://localhost:8000 자동으로 열림
5. 시작 화면에서 LED를 상하좌우 끝까지 한 번 움직임 → "✓ 범위 저장됨"
6. 엔코더 버튼(또는 시작하기 버튼)으로 게임 시작

[게임]
- LED 좌우 = 던질 방향, LED 위아래 = 던질 거리 (멀리 던질수록 큰 물고기)
- 조이스틱 위/아래 끝까지 = 캐스팅
- "입질!" → 1~1.7초 안에 챔질 (빨리 할수록 PERFECT 보너스)
- 엔코더 = 릴. 물고기가 달아날 때(노란 안내)는 감지 말고,
  낚싯대(LED)를 물고기 반대쪽으로 당기면 장력이 줄어요
- 장력 게이지가 빨간 구간에 머물면 줄이 끊어져요
- 연속으로 낚으면 콤보 점수 배수 증가

[🔪 손질 타임 — 3분이 끝나면]
- 잡은 물고기(최대 6마리)를 작은 것부터 도마에 올려 회를 떠요
- 흰 막대 두 개가 양쪽에서 빨간 선으로 다가와요. 닿는 순간 LED(칼)를 아래로 내려치기
  (엔코더 버튼 / Space / 마우스 클릭도 가능)
- 판정: PERFECT · GREAT · SUCCESS · BAD,  연속 성공하면 콤보 보너스
- 큰 물고기는 중간에 "뒤집기!" → 기울기 센서를 기울여요 (2.5초 안에 하면 +50)
- 판정이 늘 늦거나 빠르게 나오면 지연 보정값 조절:
  http://localhost:8000/?lat=0.18  (늦게 판정되면 값을 키우고, 빠르면 줄이기. 기본 0.12)

[LED 인식이 불안정할 때]
- 카메라 뒤 창문/조명 피하기, LED를 카메라 쪽으로
- 방이 밝으면: launch.bat 172.30.1.93 --exposure -6  (화면이 어두워지고 LED만 또렷해짐)
- 카메라가 여러 대면: launch.bat 172.30.1.93 --camera 1
- 연습 시간 바꾸기: 브라우저 주소 http://localhost:8000/?t=60  (60초)
